#  Timer em Python

Mini projeto de um contador regressivo em Python para rodar no terminal.  
O usuário informa o tempo em segundos e o programa exibe a contagem no formato **MM:SS**, atualizando a cada segundo até o tempo se esgotar.

---

## Como executar

1. Certifique-se de ter o Python 3 instalado
2. Clone o repositório ou baixe os arquivos
```
git clone [https://github.com/ricardosouzaj26/timer.git](https://github.com/ricardosouzaj26/timer.git)
```
3. No terminal, entre na pasta do projeto:
```
cd timer
```  
Execute o jogo:
```
python timer.py
