#  Timer em Python

Mini projeto de um contador regressivo em Python para rodar no terminal.  
O usuário informa o tempo em segundos e o programa exibe a contagem no formato **MM:SS**, atualizando a cada segundo até o tempo se esgotar.

---

## ▶️ Como executar

1. Verifique se você tem o Python 3 instalado:
```bash
python --version
```
2. Clone o repositório:  
```bash
git clone https://github.com/ricardosouzaj26/timer-python.git  
cd timer-python
```  
3. Execute o programa:  
```bash
python timer.py
```
